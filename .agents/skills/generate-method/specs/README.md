## Regenerating

```bash
python3 utils/extract-specs.py .claude/skills/generate-method/SKILL.md --stats
```

## Rule ID Scheme

Format: `@rule:<category>-<NNN>`

| Category | Scope |
|---|---|
| `structural` | JSON shape, required sections, element counts |
| `semantic` | Alpha relationships, cross-references, type correctness |
| `naming` | Element names, descriptions, name uniqueness |
| `coverage` | Completeness of state/activity/pattern mapping |
| `narrative` | Citation linkage, placement, quality, self-containment |
| `process` | Workflow steps, phase ordering, gate checks |
| `aliasing` | Terminology aliases, keywords, domain term handling |

ID range for generate-method: 001–199 within each category.
