## Review recipe

Recipe version: 2.0.0. Apply only when a series explicitly selects this file.
The series configuration owns membership, focus, related calendars and sources.

Use the configured business-picture recipe for the review period. Keep forecast
measures separate from booked actuals and quota attainment. Focus coverage
supplies no quota amount. Preserve overlapping scope meanings.

For All Hands, the first held occurrence in Jan–Mar, Apr–Jun, Jul–Sep or Oct–Dec
is the quarter opener. Read all held All Hands and weekly syncs in the previous
quarter using configured related series titles; paginate rather than assume a
fixed count covers a quarter. No private 1:1 notes. Review the previous quarter's
booked results and evidenced meeting outcomes, then propose new-quarter priorities
against current pipeline. Later All Hands checks recorded priorities; missing
priorities stay unknown. Weekly meetings do not become goal-setting workshops.

Read every page of the configured team requests report and filter using the
configured request helper with all configured members and aliases.
Fixtures replace live calls. Preserve request codes, handler, customer, partner,
type, platform, scheduled start, effort and plan in private evidence. Only
audience-appropriate details and exceptions belong in the shared Analysis;
only exceptions needing shared input become agenda candidates. Missing pages
mean partial coverage, never closure. Compare against prior snapshots before
describing a change. A closed request is not necessarily finished work, a
technical win or booked revenue. Do not rank people by effort.

Recognition uses evidenced, shareable contributions from transcripts, peer thanks
or rewards. When configured, read reward HTML if plain text is a stub; exclude
anniversaries. Match the configured member emails/names. Do not import private
critical feedback or create manager prompts in the team report. A recognition
source being unavailable is a coverage gap, not evidence of no contributions.

Use the locally copied focus and facilitation references as context. Prefer
topics needing alignment, a decision or transferable learning; routine work
continues with its owner. Treat people fairly, invite different perspectives and
keep proposed owners distinct from accepted commitments. Cite a publication
only after reading its relevant passages; an old brief is interpretation.
